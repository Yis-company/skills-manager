# Triage labels

| Role | Linear label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate |
| needs-info | needs-info | Waiting on reporter information |
| ready-for-agent | ready-for-agent | Fully specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation or a human-owned decision |
| wontfix | wontfix | Will not be actioned |

At assessment, only ready-for-agent and ready-for-human existed. The other three labels are unprovisioned. Verify availability before applying labels; report missing labels rather than silently creating or substituting them. This setup does not provision remote labels.

Wayfinder maps and decision tickets retain only their established wayfinder labels.
